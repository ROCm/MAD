# Logo sources and notices

MAD is an AMD open-source project, so the site carries the AMD logo in its header and AMD's
copyright, legal links and trademark attribution in its footer, following AMD's ROCm documentation.

The site also shows the logos of the model providers, frameworks and hardware it describes,
so that a reader can recognize them at a glance. They are used only to identify those products.
**All names and logos are trademarks of their respective owners**; their inclusion does not imply
endorsement by, or affiliation with, those owners.

## What is here

| Path | Contents | Source |
|------|----------|--------|
| `providers/<hf-org>.png` | 96x96 avatars of model providers, named by Hugging Face organization | The vLLM recipes site (https://recipes.vllm.ai/providers/), which shows the same Hugging Face organization avatars; otherwise the Hugging Face organization avatar API |
| `simple-icons/<name>.svg` | Brand marks for vLLM, PyTorch, Docker and Hugging Face | [Simple Icons](https://simpleicons.org) v16.36.0, artwork released under CC0 1.0 (trademarks remain with their owners) |
| `amd/amd-logo.svg` | The AMD logo in the site header, linked to amd.com. All shapes of the artwork unchanged; only the fill is set to the text color, so it shows as the black or white one-color logo with the theme | AMD's ROCm documentation theme ([rocm-docs-core](https://github.com/ROCm/rocm-docs-core), `amd-header-logo.svg`) |
| `amd/favicon.svg` | The AMD Arrow alone (the same artwork's arrow shapes), as the site favicon, as amd.com uses it | same file |
| `sources.json` | The exact URL each file was downloaded from | generated by `tools/dashboard/fetch_logos.py` |

Frameworks without a vendored mark (SGLang, ATOM, xDiT, Primus, JAX), and any provider without a
logo, are shown as generated monograms. The section icons (cube, layers, shield, ...) are line
glyphs drawn for this site (`tools/dashboard/icons.py`).

## Updating

Edit `dashboard/icons.yaml` (the `providers`, `name_patterns` and `frameworks` lists), then run

    pip install pillow
    python3 tools/dashboard/fetch_logos.py

Files already present are kept; use `--force` to download them again.

## Opting out, or removing a logo

* Set `logos: neutral` in `dashboard/icons.yaml` (or build with `--logos neutral`) to replace every
  brand mark with a neutral monogram or glyph, with no other change to the site.
* To remove one logo, delete its file and its entry in `sources.json`; it then renders as a monogram.
  Rights holders can ask for removal by opening an issue on this repository.
